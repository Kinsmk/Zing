## Usage Guidelines

### Logo Usage
- **Primary Logo**: Use on white or light backgrounds
- **Dark Logo**: Use on dark backgrounds (invert colors)
- **Icon Only**: Use when space is limited
- **Minimum Size**: Logo should not be smaller than 100px width

### Color Usage
- **Primary**: Use `#4F46E5` as the main brand color
- **Secondary**: Use `#7C3AED` and `#06B6D4` for accents
- **Neutrals**: Use gray scale for text and backgrounds
- **Semantic**: Use semantic colors for status messages

### Accessibility
- Ensure sufficient contrast between text and background
- Primary text (`#1F2937`) on white background: AA+ 
- Primary text (`#1F2937`) on `#E5E7EB` background: AA
- Use semantic colors consistently across the application

### Dark Mode
For dark mode, use:
- Background: `#111827`
- Surface: `#1F2937`
- Text: `#F9FAFB`
- Secondary Text: `#9CA3AF`
