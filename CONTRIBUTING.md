# Contribution à Zinga

Merci de votre intérêt pour contribuer à Zinga ! Voici comment vous pouvez aider.

## 📋 Code de conduite

En participant à ce projet, vous acceptez de respecter notre [Code de conduite](CODE_OF_CONDUCT.md).

## 🚀 Comment contribuer

### 1. Signaler un bug

- Vérifiez que le bug n'a pas déjà été signalé
- Ouvrez une issue avec une description claire
- Incluez des étapes pour reproduire le bug
- Ajoutez des informations sur votre environnement

### 2. Proposer une fonctionnalité

- Ouvrez une issue pour discuter de la fonctionnalité
- Expliquez le cas d'usage
- Décrivez l'API proposée

### 3. Soumettre une Pull Request

- Forkez le dépôt
- Créez une branche pour votre fonctionnalité (`git checkout -b feature/nouvelle-fonctionnalite`)
- Commitez vos changements (`git commit -m 'Ajout nouvelle fonctionnalité'`)
- Poussez vers votre fork (`git push origin feature/nouvelle-fonctionnalite`)
- Ouvrez une Pull Request

## 📝 Conventions de code

- Utilisez TypeScript
- Respectez le style existant
- Ajoutez des tests pour les nouvelles fonctionnalités
- Documentez votre code
- Gardez les commits atomiques

## ✅ Critères d'acceptation

- Tous les tests passent
- Le code est linté
- La documentation est mise à jour
- Les changements sont compatibles avec la roadmap

## 🤝 Communication

- Utilisez les issues pour les discussions techniques
- Utilisez les discussions GitHub pour les questions générales

## 🎯 Priorités

Consultez la [Roadmap](ROADMAP.md) pour voir les priorités actuelles.
